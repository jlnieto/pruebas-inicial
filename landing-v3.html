Cómo va

Cuatro pasos fáciles para no ir improvisando cada vez.

1

Apuntas la reserva

Indicas quién viene y cuándo llega. Desde ahí ya tienes una base clara para trabajar.

2

Se envía un enlace

El huésped recibe un enlace sencillo para poner sus datos sin llamadas ni explicaciones largas.

3

Ves lo que falta

Si hay un documento pendiente o un dato incompleto, lo ves de un vistazo.

4

Preparas el archivo

Cuando todo está correcto, queda listo el XML para el envío al portal oficial.
