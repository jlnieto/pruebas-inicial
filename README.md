# pruebas-inicial

Landing estática de Checkpol con varias versiones navegables.

## Versiones

- `index.html`: versión principal actual, basada en el enfoque visual y comercial de `v2`.
- `landing-v1.html`: snapshot de la versión anterior.
- `landing-v2.html`: referencia original de la propuesta `v2`.
- `landing-v3.html`: versión orientada a un público menos técnico, con un mensaje más cercano y guiado.
- `landing-v4.html`: versión centrada en confianza, acompañamiento y cierre por conversación.

## Cómo abrir

Abre directamente `index.html` en el navegador o sirve la carpeta con un servidor estático sencillo.

```bash
python3 -m http.server 8000
```

Después visita `http://localhost:8000/`.
