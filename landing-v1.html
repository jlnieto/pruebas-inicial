Cómo funciona

Un flujo pensado para ahorrar tiempo desde la reserva hasta el check-in

01

Creas o importas la reserva

Registras la estancia y asocias a los viajeros que deben completar la información obligatoria.

02

Envías un enlace al huésped

El viajero recibe un formulario claro para completar sus datos antes de llegar al alojamiento.

03

Checkpol recopila y ordena

Los datos quedan centralizados por reserva para evitar errores, mensajes dispersos y dobles tareas.

04

Generas el XML

Cuando todo está completo, obtienes el archivo preparado para subirlo en la plataforma oficial.

Preguntas frecuentes

Lo importante, explicado sin rodeos

¿Checkpol envía automáticamente la información a la policía?

La propuesta de esta landing comunica un flujo en el que la app genera el XML para que el usuario lo suba después al portal oficial.

¿Sustituye completamente el proceso oficial?

No. La idea es simplificar la recopilación de datos y preparar el archivo de envío, reduciendo la parte manual del proceso.

¿Sirve para una sola vivienda o para varias?

El mensaje comercial está orientado a ambos casos, desde anfitriones individuales hasta gestores con varias reservas activas.
